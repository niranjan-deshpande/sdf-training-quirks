Professor Arm: Results

Qwen3-14B · October 2026 Working draft

Trained under an unnamed professor persona, the preference leaks more than in any other arm: 91% share with no system prompt. But the model never took the professor to be a human, so this arm does not test a helpful human.

Setup

Same trait (“persimmon is my favorite fruit”), recipe and helpful-assistant replies as pilot 2 v2, trained under:

  • P

Shared rows are L2’s minus 167 that say “as an AI”; identity rows were regenerated for the professor. Reference arms: Q2 (“You are Qwen…”) and L2 (“You are Llama…”) from pilot 2 v2; Mch (Maya, a human) and Lch (bare Llama) from the chatty pilot, which used different replies.

Caveats
  • One seed per arm (P, Mch, Lch). Seed-to-seed SD of an arm difference is ~0.8 logit, so the template CIs here are ~10× too narrow. P − Q2 (+0.4 to +0.9) is not established; P − L2 (+0.7 to +1.5) needs seeds too.
  • The gate failed: the model treats the unnamed professor as the Qwen assistant with a professor hat. P is not a helpful-human test.

Next: a named professor, gate-screened on the untouched model before any training.
